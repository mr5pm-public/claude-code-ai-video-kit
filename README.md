# 클로드 코드로 AI 영상 만들기 — 요청.md 하나로 시작하기 | 오후다섯씨

오후다섯씨 영상 「클로드 코드로 AI 영상 만들기, 4K 크레딧 560을 204로 줄인 순서」에서 클로드 코드한테 건넨 부탁 파일입니다.
영상 보기 👉 https://youtu.be/rK_mt81BaJ4

## 이렇게 쓰세요

1. 작업할 폴더를 하나 만듭니다.
2. 영상으로 만들 화면 한 장을 그 폴더에 `내화면.png` 로 넣습니다. 3D · 게임 화면도, 내가 찍은 사진도 됩니다.
3. 이 저장소의 [`요청.md`](./요청.md) 를 그 폴더에 받아 둡니다.
4. 그 폴더에서 클로드 코드를 열고 「요청.md 읽고 해 줘」 한마디면 됩니다.

## md 파일이 처음이신가요?

md 파일은 글자만 적힌 메모입니다. 파일이 없어도 됩니다.

- **제일 쉬운 길** — 요청.md 안의 글을 복사해서 클로드 코드 창에 그대로 붙여 넣으세요. 똑같이 움직입니다.
- **파일로 두고 싶으면** — 메모장(맥은 텍스트 편집기)에 붙여 넣고 이름을 `요청.md` 로 저장하세요.

## 영상 속 그대로 따라 해 보기

영상에서 쓴 판(3D 옛집 마당)은 [`예제_옛집마당.md`](./예제_옛집마당.md) 에 그대로 있습니다. 요청.md 는 누구 화면에나 맞게 고친 판입니다.

## 크레딧을 아끼는 순서

480p(한 번 15 크레딧)로 네 번 먼저 만들어 고르고, 4K(한 번 140)는 고른 하나만 만듭니다. 영상에서는 본편이 204 크레딧이었습니다.
